OpenNodeDesk — бесплатный, портативный и ориентированный на работу офлайн клиент удалённого администрирования для системных администраторов Windows, построенный на WPF (.NET 10). Он объединяет три типа подключений (RDP, SSH и VNC), инвентарь assets и connection templates в одном локальном приложении: без учётной записи, данные не покидают ваш компьютер.

> Ранее проект назывался RemotePilot, переименован 2026-11-14. Имена пакетов версий v2.3.0 и более ранних по-прежнему `RemotePilot-*.zip`, после распаковки запускается `RemotePilot.exe`; начиная с этой версии используется единое имя OpenNodeDesk.

## Основные возможности

### Подключения

- **Прямое подключение RDP**: динамически создаёт файл `.rdp` и подключается через системный `mstsc.exe`, без сторонних посредников; поддерживает разрешение, глубину цвета, перенаправление дисков / буфера обмена / звука, а также быстрые настройки разделения на две части (по горизонтали и по вертикали).
- **Встроенный терминал SSH**: на базе SSH.NET и VirtualTerminal.WPF, двойная аутентификация по паролю и приватному ключу (приоритет у ключа), поддерживает переход через **jump host SSH**.
- **Передача файлов SFTP**: одной кнопкой на панели терминала открывается окно передачи — можно просматривать каталоги, загружать, скачивать, обновлять и переходить по путям; в сценарии с jump host используется тот же туннель переадресации.
- **VNC**: запускает уже установленный на машине VNC-клиент (TightVNC / UltraVNC / RealVNC / TigerVNC), поддерживает пользовательские шаблоны параметров и автоматическое определение пути к клиенту.

### Управление assets

- **Asset hub**: группы, избранное, недавние, напоминания о сроке, заметки и пользовательские поля, два режима — таблица / карточки.
- **Импорт и экспорт**: массовый импорт из CSV / Excel (автодедупликация и подтверждение конфликтов), экспорт по полям; также можно получать assets из собственного HTTP-интерфейса (массив JSON или текст CSV).
- **Проверка доступности**: проверяет доступность узла по одному или пакетно, результат записывается обратно в asset.
- **Шаблон подключения**: многоразовые шаблоны параметров подключения с пресетами разрешения и разделения экрана.

### Сессионное рабочее пространство

- Несколько сессий на одном экране, ячейки подстраиваются; полноэкранный режим отдельной ячейки, отключение и индикаторы состояния — всё наглядно.
- Кнопка «Открыть» на панели инструментов ищет по **имени asset / адресу / группе** и сразу открывает сессию.

### Безопасность и конфиденциальность

- **Приоритет офлайна**: все данные хранятся локально, без учётной записи, телеметрии и требования подключения к сети.
- **Пароли по умолчанию не сохраняются**; при установке флажка «Запомнить пароль» они шифруются на диске средствами Windows DPAPI (текущий пользователь).
- **Protection passphrase**: можно задать passphrase, которая блокирует приложение по тайм-ауту простоя или вручную сразу; при утрате её можно сбросить с помощью **recovery code**. После 5 неверных вводов passphrase подряд отключается только ввод passphrase; «Очистить локальные данные» остаётся только после ещё 5 неверных вводов recovery code подряд (что нужно заранее разрешить в настройках).

### Интерфейс

- Мгновенное переключение светлой / тёмной темы, синхронно во всех окнах.
- Язык интерфейса: 13 вариантов (简体中文, 繁體中文, English, 日本語, 한국어, Deutsch, Français, Español, Русский, Português, Italiano, Türkçe, Tiếng Việt); переключение применяется сразу и запоминается.

## Быстрый старт

1. Откройте «Asset hub», нажмите «Новый asset», укажите имя, хост, порт и протокол (для RDP по умолчанию 3389, SSH — 22, VNC — 5900).
2. Для протоколов, требующих учётных данных, будет предложено ввести пароль; он сохранится только если установить флажок «Запомнить пароль».
3. Дважды щёлкните по asset или нажмите «Подключить»; RDP откроет окно mstsc, SSH — встроенный терминал.
4. После установки SSH-соединения нажмите «Файлы SFTP» на панели терминала, чтобы загружать / скачивать файлы.
5. Чтобы видеть несколько машин одновременно, перейдите в «Сессионное рабочее пространство», нажмите «Открыть», найдите assets и добавьте их.
6. Сохраните часто используемые параметры как «Шаблон подключения» и применяйте их напрямую при создании asset.

## Данные и безопасность

- Данные assets хранятся в `%LOCALAPPDATA%\FastRdp\RemoteOps\assets.json`; для резервного копирования или переноса достаточно скопировать этот файл.
- Для совместимости с прошлыми версиями каталог данных по-прежнему `%LOCALAPPDATA%\FastRdp\RemoteOps\`, независимо от имени программы.
- По умолчанию пароли не сохраняются. Они сохраняются, только если установить флажок «Запомнить пароль», шифруются средствами Windows DPAPI (текущий пользователь) и могут быть расшифрованы только под тем же пользователем Windows.
- При каждом подключении RDP в `%TEMP%\OpenNodeDesk\{случайная папка}\` создаётся временный файл `.rdp`, содержащий зашифрованное средствами DPAPI поле пароля; его можно безопасно удалить.
- Перед включением protection passphrase рекомендуем сначала сделать резервную копию assets через «Экспортировать выбранное».

## Частые вопросы

- **Отметили перенаправления RDP, но они не работают?** После более свежих обновлений безопасности Windows при открытии неподписанного `.rdp` сначала появляется диалог безопасности, в котором перенаправления буфера обмена, дисков, принтеров и т. п. по умолчанию отключены и их нужно один раз отметить вручную. Приложение уже записывает в `.rdp` такие ключи, как `redirectclipboard:i:1`, согласно вашим отметкам, но этот шаг за вас отметить нельзя. Чтобы совсем избежать отметки, нужно подписать `.rdp`, либо чтобы ИТ-служба доверяла указанному издателю через групповые политики.
- **Заголовок окна RDP показывает «имя (IP)»?** Заголовок mstsc берётся из имени файла `.rdp`, а приложение называет его «имя asset (адрес хоста).rdp».
- **После подключения по VNC в рабочем пространстве страница-заглушка?** Удалённое изображение размещается в собственном окне локального VNC-клиента; само приложение не содержит VNC-клиента.
- **Пароль SSH неверен?** Приложение предложит ввести его заново и переподключиться; для одного asset это предлагается один раз, чтобы не появлялись повторяющиеся окна.
- **Не удаётся подключиться к jump host?** У самого asset jump host должен быть рабочий пароль или приватный ключ; если нет ни того, ни другого, соединение завершится ошибкой ещё до начала.

Более полное описание — в разделе «Справочное руководство» внутри приложения.
